## The question

Strive was paying for a SaaS package that cost more than it delivered: a subscription for the whole organisation, of which part of the features were used and whose way of working did not match how Strive works. The question was one we hear often: "We are done with our current package. We want something that fits."

<div class="bg-stone-50 p-6 md:p-8 mb-8 border-l-4 border-brand-blue not-prose">
  <h3 class="text-xl font-serif text-brand-dark mb-3">What it was about</h3>
  <ul class="space-y-2 text-stone-600 list-disc ml-5">
    <li><strong>Cost:</strong> a subscription that comes back every year, for features that largely went unused</li>
    <li><strong>Fit:</strong> a package that dictates the way of working, instead of software that follows the work</li>
    <li><strong>Ownership:</strong> data and process that sat with a vendor, not with Strive</li>
  </ul>
</div>

## How we approached it

First map what the package actually did for Strive, what was used and what it was connected to. Then we built the custom software alongside the package, with only the features Strive uses and with the integrations the package never had. The subscription was cancelled only once the new system was running.

<div class="grid md:grid-cols-2 gap-6 mb-8 not-prose">
  <div class="p-6 bg-white border border-stone-200"><h4 class="font-bold text-brand-dark mb-2">Only what is used</h4><p class="text-sm text-stone-600">No features that exist because a vendor once thought of them. Software that follows Strive's work.</p></div>
  <div class="p-6 bg-white border border-stone-200"><h4 class="font-bold text-brand-dark mb-2">Built alongside the old</h4><p class="text-sm text-stone-600">No big bang. The new system ran in parallel until the numbers matched; then the subscription went.</p></div>
  <div class="p-6 bg-white border border-stone-200"><h4 class="font-bold text-brand-dark mb-2">Business case first</h4><p class="text-sm text-stone-600">Before the build, one page showed what the package cost, what the custom software costs and when the replacement pays back.</p></div>
  <div class="p-6 bg-white border border-stone-200"><h4 class="font-bold text-brand-dark mb-2">Owned by Strive</h4><p class="text-sm text-stone-600">Source code, documentation and data model belong to Strive. The team was trained on managing it.</p></div>
</div>

## The result

The SaaS package is gone. Strive works in its own software that fits the way the organisation works, without an annual subscription and with data that belongs to Strive.
